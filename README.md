# 🚀 Ollama + Open WebUI + Docker Desktop en Windows 11

Guía completa para instalar una plataforma de IA local utilizando:

- Ollama
- Docker Desktop
- Open WebUI
- Qwen3
- DeepSeek-R1
- Mistral
- Llama 3.2
- Kimi K3.1 Pro

---

# Arquitectura

Windows 11
│
├── Ollama
│   ├── qwen3
│   ├── deepseek-r1
│   ├── mistral
│   └── llama3.2
│
├── Docker Desktop
│
└── Open WebUI
    └── http://localhost:3000

---

# Requisitos

- Windows 11
- WSL2
- Docker Desktop
- 16 GB RAM mínimo
- 32 GB RAM recomendado
