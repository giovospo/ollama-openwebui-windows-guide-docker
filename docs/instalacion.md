# Instalación

## Instalar Ollama

```powershell
irm https://ollama.com/install.ps1 | iex
```

Verificar:

```powershell
ollama --version
```

## Descargar modelos

```powershell
ollama run qwen3
```

```powershell
ollama run deepseek-r1
```

```powershell
ollama run mistral
```

```powershell
ollama run llama3.2
```

## Ver modelos

```powershell
ollama list
```

## Verificar WSL

```powershell
wsl --status
```
